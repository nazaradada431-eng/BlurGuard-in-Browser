# Streamer Text Blur v1.7

Исправлена главная проблема предыдущих версий: встроенный список теперь
действительно загружается в `blockedWords` при первом запуске.

Встроенных записей: 79.

Поддерживается:
- Twitch chat и другие динамические чаты;
- комментарии;
- списки;
- обычный текст;
- iframe;
- открытый Shadow DOM;
- новые DOM-узлы через MutationObserver;
- регистр не важен;
- разделители между буквами не мешают совпадению;
- Ctrl/Alt/Shift + клик раскрывает конкретный фрагмент на 3/5/10 секунд.

После замены расширения в Firefox:
about:debugging -> This Firefox -> Streamer Text Blur -> Reload

Если в настройках уже был сохранён старый `blockedWords`, новая версия
не перезапишет его автоматически. Чтобы получить новую встроенную базу,
в popup нужно очистить список и нажать Save, либо удалить данные расширения
и загрузить v1.7 заново.


## v1.8

Добавлено:

- фильтрация текста, который пользователь вводит в `input` и `textarea`;
- поиск/чатовые поля на сайтах;
- маскирование запрещённого текста в `document.title`, поэтому он скрывается и в названии вкладки;
- браузерную адресную строку расширение изменить не может: это интерфейс самого Firefox/Chrome, а не содержимое веб-страницы.
